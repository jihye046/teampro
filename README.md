## 👥 Members & Contributions

### **하지혜 (본인)**

#### ⚙️ 핵심 로직 개발 (Core Logic)
- **Multi-API Integration**: 맛집, 명소, 호텔, 주차장, 카페 등 7종 이상의 공공데이터 API 분석 및 가공하여 정보 제공 게시판 구현
- **Asynchronous Interaction**: AJAX 기반 비동기 댓글/대댓글 CRUD 및 실시간 정렬 로직 설계
- **Efficient Paging**: 대량의 API 데이터 처리 최적화를 위한 비동기 페이징 처리
- **DB Optimization**: 실무 로직에 맞춰 기존 테이블 구조 세부 조정 및 정규화 보완

#### 🎨 디자인 및 관리 (Design & PM)
- **UI/UX Directing**: 전반적인 서비스 레이아웃 설계 및 공통 디자인 시스템(CSS) 구축
- **Documentation**: 프로젝트 기술 산출물(발표 자료 등) 총괄

---

### **Team Members**
- **팀원 A**: 전반적인 DB 데이터 모델링 설계, 텍스트 에디터 기반 여행 후기 커뮤니티 구현
- **팀원 B**: Spring Interceptor 기반 권한 처리, 로그인/회원가입 및 메일 API 활용 비밀번호 찾기 구현
- **팀원 C**: 마이페이지 정보 관리 및 본인 인증 시스템, 활동 기반 포인트/쿠폰 교환 로직 구현
